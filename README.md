# Simple Shell

This is a simple UNIX command line interpreter created as part of the Holberton School curriculum.

## Description

This project is a simple shell that can execute commands, handle arguments, and manage the PATH. It replicates basic functionality of the sh shell.

## Files

- `README.md` - This file
- `man_1_simple_shell` - Manual page for the shell
- `AUTHORS` - List of contributors
- `main.c` - Main shell loop
- `reader.c` - Input reading functions
- `tokenizer.c` - Command parsing functions
- `path_finder.c` - PATH resolution functions
- `executor.c` - Command execution functions
- `shell.h` - Header file
